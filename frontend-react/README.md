# Smart Hydro Alert Frontend

React dashboard for the Smart Hydro Alert project.

## Run Locally

Install the packages:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The dashboard runs at:

```text
http://localhost:5173
```

By default, it connects to the FastAPI backend at:

```text
http://localhost:8000
```

A different backend URL can be set with `VITE_API_BASE`.

## Checks

Run ESLint:

```bash
npm run lint
```

Build the frontend:

```bash
npm run build
```
